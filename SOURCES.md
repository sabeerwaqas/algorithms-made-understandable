# Sources and learning references

This repository contains original explanations, examples, Java implementations, diagrams, and animations. These links identify the course scope and references used to check the topic coverage. Handout pages are not reproduced here.

## Primary course references

1. [Virtual University OpenCourseWare — CS502 Fundamentals of Algorithms](https://ocw.vu.edu.pk/CourseDetails.aspx?cat=Computer+Science%2FInformation+Technology+&course=CS502) — official course information and contents.
2. [Virtual University OpenCourseWare — CS502 lectures](https://ocw.vu.edu.pk/Videos.aspx?cat=Computer+Science%2FInformation+Technology+&course=CS502) — official lecture sequence.
3. [VU LMS — CS502 Lecture 01 PDF](https://vulms.vu.edu.pk/Courses/CS502/Lessons/Lesson_1/Lecture%2001.pdf) — introductory material including algorithm analysis motivation and the RAM model.

The root README preserves the 48-item LMS index supplied for this learning path. The OpenCourseWare calendar numbers its welcome item from zero; this repository follows the LMS numbering supplied by the learner so the index matches the portal.
